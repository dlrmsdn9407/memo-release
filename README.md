# 업무 기억

업무 내용을 아무렇게나 넣어두고, 나중에 연관된 것을 찾아주는 프로그램.

## 받기

[**최신 버전 내려받기**](https://github.com/dlrmsdn9407/memo-release/releases/latest) → `memo.exe`

설치 필요 없다. 아무 폴더에나 두고 두 번 누르면 된다.

**윈도우가 "알 수 없는 발행자" 라고 막으면** [추가 정보] → [실행].
서명서를 사지 않아서 뜨는 것이고 한 번만 넘기면 된다.

## 처음 켜면

저장할 폴더를 묻는다. 고르고 나면 바로 쓸 수 있고,
**매일 저녁 6시 자동 백업**과 **예약 알림**이 자동으로 켜진다.

휴대폰 알림(카카오톡·텔레그램·이메일·구글 캘린더)은 **선택**이다.
쓰려면 각자 자기 열쇠를 등록해야 하고, 순서는 프로그램 안 [도움말] 에 있다.

## 문제가 생기면

프로그램 왼쪽 아래 **[문제]** → [전체 복사] 로 만든 글을 만든 사람에게 보내면 된다.
기록 내용은 담기지 않는다.
